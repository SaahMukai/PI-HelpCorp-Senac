## 🚀 Como Executar e Apresentar a Landing Page

A landing page foi desenvolvida com padrões web modernos (HTML5, Tailwind CSS, JavaScript Vanilla e CSS3), sem dependências complexas de compilação ou Node.js.

### Opção 1: Execução Direta no Navegador (Mais Rápido)
1. Navegue até a pasta:
   ```
   C:\Users\User\.gemini\antigravity\scratch\helpcorp-landing-page\
   ```
2. Dê um duplo clique no arquivo **`index.html`** para abri-lo no Google Chrome, Microsoft Edge ou Firefox.

### Opção 2: Servidor Local via PowerShell (Opcional)
Se desejar rodar em um servidor local HTTP:
```powershell
cd C:\Users\User\.gemini\antigravity\scratch\helpcorp-landing-page
python -m http.server 8080
```
Em seguida, abra no navegador: `http://localhost:8080`

## 💡 Dicas para a Apresentação com a Banca / Professor

1. **Demonstre o Simulador ao Vivo:**
   - Na apresentação de slides ou telão, clique no botão **"💻 Caso Camila: Notebook travado"**.
   - Mostre como a IA identifica na hora a categoria `TI > Hardware > Notebooks`, a urgência `Crítica/Alta` e sugere o artigo de reinicialização.
   - Clique em **"Abrir Chamado Agora"** e mostre a geração do protocolo `#4821`.
   - Em seguida, mude para a **"Visão Gestor (Ricardo)"** para mostrar o chamado já caindo na fila com o cronômetro do SLA ativo e alerta de escalonamento.
2. **Mostre a Calculadora de ROI:**
   - Arraste o slider para empresas de 500 colaboradores e mostre a redução de centenas de horas de retrabalho manual.
3. **Destaque a Seção de LGPD:**
   - Ressalte para a banca a preocupação do grupo com segurança jurídica (retenção de 5 anos, criptografia e portal de privacidade).
